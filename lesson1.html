    같은 사진, 다른 필터

    필터의 색감 차이는 어떻게 생기는 걸까요?

    🎨 미리 알아두기: 색 하나 = 숫자 3개

    화면의 모든 점(픽셀)은 빨강(R), 초록(G), 파랑(B) 세 빛을 섞어서 색을 내요. 각 빛의 세기를 0(꺼짐)부터 255(가장 밝게)까지의 숫자로 나타내요.
    그래서 점 하나의 색은 (R, G, B) 숫자 3개예요.

    👆 왼쪽 원본 사진 위에 마우스를 올려 보세요. 그 점의 숫자 3개와, 오른쪽 사진들의 같은 위치 숫자가 함께 나타나요. 클릭하면 위치가 고정돼요.

    * 원본 옆 4가지 필터는 인스타그램에 실제로 있는 필터입니다!
    * 인스타그램 필터의 실제 계산식은 공개되어 있지 않아서, 필터의 느낌을 보고 비슷하게 만든 필터예요.

    다섯 사진 모두 같은 위치의 점인데 숫자가 달라요. 필터는 사진 속 숫자를 "규칙"에 따라 계산해 바꾸는 것이에요.

    각 필터들의 RGB 값의 특징을 정리해봅시다.
    2

    픽셀 하나 = 숫자 하나

    흑백 그림의 칸(픽셀) 하나는 숫자 하나예요. 0은 검정, 255는 흰색, 그 사이는 회색이에요.

    칸을 칠하면 행렬의 숫자가 바로 바뀌어요.

    8×8 행렬 A

    흑백 이미지는 행렬이에요. (i, j) 성분은 위에서 i번째 줄, 왼쪽에서 j번째 칸의 밝기예요.

    Q. '이 행렬을 그림으로!'의 숫자대로 칸을 칠해 보세요. 어떤 그림이 나오나요?

    이 행렬을 그림으로!
    검정(0)과 흰색(255)만 쓸 때와 회색(64, 128, 192)까지 쓸 때, 그림은 어떻게 달라지나요?

    4

    색 하나 = 숫자 3개 (R, G, B)

    화면의 모든 색은 빨강(R), 초록(G), 파랑(B) 빛을 섞어 만들어요. 각각 0~255의 숫자예요.

    회색을 만드는 규칙을 찾았나요? R, G, B가 어떤 관계일 때 회색이 되나요?
    5

    컬러 사진 = 행렬 3장

    사진의 모든 픽셀에서 R 숫자만 모으면 R 행렬, G만 모으면 G 행렬, B만 모으면 B 행렬이 돼요.

    7

    필터의 정체와 나만의 필터

    필터는 새로운 R′, G′, B′를 원래 R, G, B로 계산하는 규칙이고, 모든 픽셀에 같은 규칙을 적용해요. 대표 규칙 두 가지를 살펴본 뒤, 식을 직접 써서 나만의 필터를 만들어 보세요.

    🔄 반전 필터

    R′ = 255 − R, G′ = 255 − G, B′ = 255 − B

    밝은 곳(큰 수)은 어둡게, 어두운 곳(작은 수)은 밝게 바뀌어요.

    ⚫ 흑백 필터

    R′ = G′ = B′ = (R + G + B) ÷ 3

    세 숫자를 같게 만들면 회색이 돼요 (4번 화면에서 찾은 규칙!).

    🛠 나만의 필터 만들기 R, G, B, 숫자, + − × ÷ ( ) 를 쓸 수 있어요

    결과

    계산 결과가 0보다 작으면 0, 255보다 크면 255가 돼요.
