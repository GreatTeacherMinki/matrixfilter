3차시

색을 바꾸는 행렬 곱

    1

    색감 필터의 비밀

    2차시의 슬라이더는 R은 R끼리, B는 B끼리 계산했어요. 그런데 세피아 같은 색감 필터는 조금 달라요.

    버튼을 누르고 사진을 클릭해 보세요.

    세피아의 R'는 원래 R만으로 만들 수 없어요. R' = 0.39R + 0.77G + 0.19B 처럼 R, G, B를 모두 섞어서 만들어요. 이런 식 3개를 깔끔하게 정리하는 도구가 바로 행렬의 곱셈이에요.

    흑백 사진에서는 R', G', B'가 모두 같아요. 세피아는 R', G', B'의 크기가 어떤 순서인가요?
    2

    식 3개 = 행렬 하나

    R', G', B'를 만드는 식 3개의 계수(곱하는 수)만 모으면 3×3 행렬이 돼요. 왼쪽 식의 숫자를 바꾸면 오른쪽 행렬도 함께 바뀌어요.

    행렬로 쓰면

    행렬의 1행 → R' 식, 2행 → G' 식, 3행 → B' 식
    픽셀 (R, G, B)는 3×1 행렬(세로로 세운 행렬)로 써요.

    1행 1열 성분이 0이면, R'를 만들 때 원래 R은 쓰일까요?
    3

    직접 곱해 보기

    행렬의 곱셈 규칙: i행의 성분과 픽셀의 성분을 차례로 곱해서 더하면 결과의 i번째 성분이에요. 빈칸을 채워 보세요.

    문제 1의 행렬은 어떤 필터일까요? 결과 픽셀의 색을 원래 색과 비교해 보세요.
    4

    대각선 성분 = 각 색의 세기

    왼쪽 위에서 오른쪽 아래로 이어진 대각선만 1이고 나머지가 0이면 단위행렬 E예요. 사진이 그대로예요. 대각선 숫자를 바꿔 보세요.

    R 세기만 0으로 하면 어떤 색의 사진이 되나요? 2차시의 '따뜻함'과 비슷하게 만들려면?
    5

    1의 자리를 옮기면 색이 이사 가요

    대각선이 아닌 자리에 1을 두면 다른 색의 값을 가져와요. 예를 들어 1행 3열이 1이면 R' = B가 돼요.

    빨간 풍선을 파란 풍선으로 바꾸려면 1을 어느 자리에 두어야 할까요?
    6

    흑백 행렬과 세피아 행렬

    유명한 필터 행렬을 살펴봐요. 행렬의 세 행이 어떤 관계인지에 주목하세요.

    세 행이 모두 같으면 왜 회색이 될까요? 각 행의 합이 1보다 크면 어떻게 될까요?
    7

    채도 = 단위행렬과 흑백 행렬 섞기

    인스타그램의 '채도' 슬라이더예요. 단위행렬 E(원본)와 흑백 행렬 G를 실수배해서 더하면 채도 행렬이 돼요.

    s = 0 이면 흑백, s = 1 이면 원본, s > 1 이면 더 쨍한 색이 돼요.
    2차시에 배운 행렬의 덧셈과 실수배가 '필터 행렬'을 만드는 데도 쓰였어요. s = 0.5 이면 어떤 행렬이 될까요?
    8

    필터 강도 슬라이더의 정체

    인스타그램에서 필터를 한 번 더 누르면 나오는 강도 슬라이더도 같은 원리예요. 단위행렬 E와 필터 행렬 F를 섞어요.

    강도 0%와 100%일 때 행렬은 각각 무엇인가요?
