3차시

색을 바꾸는 행렬 곱

    1

    식 3개 = 행렬 하나

    2차시 예고에서 본 것처럼, 세피아 같은 색감 필터는 R' = 0.39R + 0.77G + 0.19B 처럼 R, G, B를 모두 섞어서 만들어요. R', G', B'를 만드는 식 3개의 계수(곱하는 수)만 모으면 3×3 행렬이 돼요. 왼쪽 식의 숫자를 바꾸면 오른쪽 행렬과 사진이 함께 바뀌어요.

    행렬로 쓰면

    행렬의 1행 → R' 식, 2행 → G' 식, 3행 → B' 식
    픽셀 (R, G, B)는 3×1 행렬(세로로 세운 행렬)로 써요.

    1행 1열 성분이 0이면, R'를 만들 때 원래 R은 쓰일까요?
    2

    직접 곱해 보기

    앞 화면에서 식 3개를 3×3 행렬 하나로 정리했어요. 이 행렬에 픽셀 (R, G, B)를 곱하면 새 색이 나와요.
    행렬의 곱셈 규칙: i행의 성분과 픽셀의 성분을 차례로 곱해서 더하면 결과의 i번째 성분이에요. 빈칸을 채워 보세요.

    문제 1의 행렬은 어떤 필터일까요? 결과 픽셀의 색을 원래 색과 비교해 보세요.
    3

    대각선 성분 = 각 색의 세기

    왼쪽 위에서 오른쪽 아래로 이어진 대각선만 1이고 나머지가 0이면 단위행렬 E예요. 사진이 그대로예요. 대각선 숫자를 바꿔 보세요.

    4

    1의 자리를 옮기면 색이 이사 가요

    대각선이 아닌 자리에 1을 두면 다른 색의 값을 가져와요. 예를 들어 1행 3열이 1이면 R' = B가 돼요.

    🎯 미션: 빨간색과 파란색을 맞바꾸는 행렬을 만들어 봅시다

    아래 행렬의 성분 9개에 숫자를 채워 보세요. 숫자를 넣으면 위 사진에 바로 적용돼요. 빨간 풍선은 파란 풍선으로, 파란 풍선은 빨간 풍선으로 바뀌면 성공!

    5

    흑백 행렬과 세피아 행렬

    유명한 필터 행렬을 살펴봐요. 행렬의 세 행이 어떤 관계인지에 주목하세요.

    6

    채도 = 단위행렬과 흑백 행렬 섞기

    휴대폰 갤러리 사진 편집(아이폰 '사진', 갤럭시 '갤러리')에 있는 '채도'는 색이 얼마나 진한지를 정해요. 단위행렬 E(원본)와 흑백 행렬 G를 실수배해서 더하면 채도 행렬이 돼요.

    s = 0 이면 흑백, s = 1 이면 원본, s > 1 이면 더 쨍한 색이 돼요.
    🎚️ 필터 앱에서 필터를 고른 뒤 효과를 얼마나 줄지 정하는 강도 조절도 같은 원리예요. 단위행렬 E와 필터 행렬 F를 섞어서 (1 − t)E + tF로 계산해요. 다음 화면에서 직접 써 봐요!
    2차시에 배운 행렬의 덧셈과 실수배가 '필터 행렬'을 만드는 데도 쓰였어요. s = 0.5 이면 어떤 행렬이 될까요?
    7

    나만의 색감 행렬 만들기

    3×3 행렬의 숫자 9개를 직접 정해서 나만의 색감 필터를 만들어 보세요. 강도 슬라이더(t)로 마지막 조절도 할 수 있어요. 결과 행렬 = (1 − t)E + tF.

    8

    이웃을 보는 필터

    지금까지 만든 필터는 모두 픽셀 하나의 숫자(R, G, B)만 보고 계산했어요. 그런데 흐림, 선명하게, 윤곽선 필터는 픽셀 하나만 봐서는 만들 수 없어요.

    흐리게 하면 경계가 부드러워지고, 선명하게 하면 경계가 또렷해져요. 경계는 픽셀과 그 이웃 픽셀의 숫자 차이예요. 그래서 이 필터들은 주변 픽셀까지 함께 계산해요.

    💡 휴대폰 사진 편집의 '선명도' 조절도 이웃 픽셀을 함께 계산하는 필터예요.

    오늘 배운 것

    생각해보기 질문에 답하고, 내 색감 행렬을 제출해요.

    색감 필터 = 3×3 행렬 × 픽셀(3×1 행렬). i행 × 픽셀 = 결과의 i번째 성분.
    단위행렬 E = 그대로, 대각선 = 색 세기, 1의 위치 = 색 이사, 세 행이 같음 = 흑백.
    채도·강도 슬라이더 = 행렬의 실수배와 덧셈으로 두 행렬 섞기.
    흐림·선명·윤곽 = 이웃 픽셀까지 보는 필터 → 3×3 커널을 옮기며 같은 자리끼리 곱해서 더하기 (4차시에 계속!)
